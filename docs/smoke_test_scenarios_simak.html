KON-01

Input Data Baru SIMAK - Konstruksi

INPUT Input Data Baru
Tujuan: Memastikan fitur input data SIMAK baru berfungsi dengan benar untuk kontrak konstruksi.
Buka halaman https://satkerpps-riau.online/admin/kontrak/simak/konstruksi
Klik tombol "Input Data SIMAK" (warna biru) di pojok kanan atas
Modal form akan muncul. Isi field-field berikut:
  • PPK: Pilih dari dropdown (contoh: NIP 199012212018021001)
  • Nama Paket: Test Paket Konstruksi Smoke [YYYYMMDDHHMMSS]
  • Tahun Anggaran: Pilih (default: tahun berjalan)
  • Penyedia: CV Test Konstruksi Indonesia
  • Nomor Kontrak: PLN/SIMAK-KONSTRUKSI/[NOMOR]/2024
  • Nilai Kontrak (Rp): 500000000 (500 juta)
  • Email Responden 1: test.konstruksi@example.com
  • Email Responden 2: responden.kedua@example.com
Klik tombol "Simpan"

Verifikasi Hasil

  • [ ] Modal menutup setelah simpan
  • [ ] Muncul pesan success (alert hijau)
  • [ ] Data baru muncul di tabel daftar SIMAK
  • [ ] Nomor kontrak sesuai dengan yang diinput
  • [ ] Nilai kontrak tertampilkan dengan formatRp (ribuan)

Kriteria Success

  • Data tersimpan ke database
  • Tidak ada error message
  • Redirect/refresh ke halaman daftar dengan data baru

Kriteria Failed

  • Form validation error (field wajib kosong)
  • Error message dari server
  • Data tidak muncul di tabel setelah refresh
KON-03

Create Share Link - Konstruksi

SHARE Share Link
Tujuan: Memastikan fitur share link SIMAK berfungsi untuk membagikan dokumen ke pihak eksternal tanpa login.
Buka halaman /admin/kontrak/simak/konstruksi
Cari data yang akan dishare (dari Scenario 1 atau data existing)
Klik tombol Share (ikon share-alt / tombol biru) pada baris data tersebut
Modal "Bagikan SIMAK" akan muncul
Pilih durasi share:
  • [ ] 1 minggu (default)
  • [ ] 30 hari
Klik tombol "Buat Link Bagikan"

Verifikasi Hasil

  • [ ] Link share terbentuk dan ditampilkan
  • [ ] Tombol "Buka Tautan" berfungsi (membuka di tab baru)
  • [ ] Tombol "Salin" berfungsi (copy ke clipboard)
  • [ ] Link mengandung format: https://satkerpps-riau.online/simak/share/[token]
KON-06

Import Excel - Konstruksi

UPLOAD Import Data
Tujuan: Memastikan fitur import data dari file Excel berfungsi dengan benar.
Buka halaman /admin/kontrak/simak/konstruksi
Klik tombol "Import Excel" (warna hijau)
Modal import akan muncul. Klik link "Download Template (XLSX)"
Verifikasi file terdownload dengan format .xlsx
Buka file template Excel, isi data test pada baris pertama:
ppk_nipnama_pakettahun_anggarannomor_kontraknilai_kontrak
199012212018021001Import Test Konstruksi 20242024 - 2025PLN/SIMAK-IMPORT-KON/[001]/2024750000000
Simpan file dengan nama: test_import_konstruksi_[YYYYMMDD].xlsx
Kembali ke modal import, pilih file yang sudah disiapkan
Klik tombol "Import"

Verifikasi Hasil

  • [ ] Proses import selesai tanpa error
  • [ ] Pesan success muncul
  • [ ] Data baru terlihat di tabel
  • [ ] Nomor kontrak sesuai dengan yang diinput di Excel
KON-10

Verifikasi Dokumen - Konstruksi

VERIFY Verifikasi Data
Tujuan: Memastikan fitur verifikasi kelengkapan dokumen berfungsi untuk memastikan semua dokumen kontrak tersedia.
Buka halaman /admin/kontrak/simak/konstruksi
Klik tombol "VERIFIKASI" (warna hijau) pada salah satu data
Verifikasi URL berubah ke: /admin/kontrak/simak/konstruksi/[ID]
Halaman menampilkan daftar dokumen yang harus diverifikasi
Pilih status verifikasi untuk salah satu dokumen:
  • [ ] Lengkap - dokumen sudah ada dan sesuai
  • [ ] Belum Sesuai - ada tapi tidak sesuai
  • [ ] Menunggu Verifikasi - belum dicek
  • [ ] Belum Ada - dokumen belum diupload
Klik tombol "Simpan Verifikasi"

Verifikasi Hasil

  • [ ] Status tersimpan ke database
  • [ ] Persentase kelengkapan berubah
  • [ ] Data terakhir diverifikasi tercatat
Test Upload (KON-12): Cari dokumen dengan status "Belum Ada", klik tombol Upload, pilih file PDF/JPG/PNG (maks 10MB). Verifikasi file berhasil diupload dan status berubah.
KON-14

Edit Data SIMAK - Konstruksi

EDIT Edit Data
Tujuan: Memastikan fitur edit data SIMAK berfungsi untuk koreksi data yang sudah tersimpan.
Buka halaman /admin/kontrak/simak/konstruksi
Klik tombol "EDIT" (warna kuning) pada salah satu data
Modal edit akan muncul dengan data yang sudah terisi
Ubah beberapa field:
  • Nama Paket: Tambahkan suffix [EDITED]
  • Nilai Kontrak: Ubah menjadi 600000000
Klik tombol "Simpan"

Verifikasi Hasil

  • [ ] Modal menutup setelah simpan
  • [ ] Data di tabel terupdate
  • [ ] Nilai kontrak baru tercermin
KON-16

Export & Download - Konstruksi

UPLOAD Export Data
Tujuan: Memastikan fitur export dan download dokumen berfungsi dengan baik.
Buka halaman /admin/kontrak/simak/konstruksi
Cari tombol/link "Export Excel" (jika ada di header/footer halaman)
Klik export dan tunggu file terdownload
Verifikasi file berekstensi .xlsx dan data lengkap
Buka halaman detail SIMAK (klik VERIFIKASI), cari tombol "Download ZIP" (jika ada)
Klik download dan verifikasi file ZIP terdownload

Verifikasi Hasil

  • [ ] File Excel terdownload dengan benar
  • [ ] Data akurat dan lengkap (semua kolom)
  • [ ] File ZIP terdownload
  • [ ] Isi ZIP sesuai dengan dokumen yang ada
